AI search agents and automated frameworks can explore unindexed or hidden parts of the web, including deep databases, login-gated sites, and Tor-based dark web .onion services. [1] (https://yutori.com/research), [2] (https://mcpmarket.com/server/onionclaw)

Top AI Search Agents & Frameworks

*   OnionClaw

    Extends AI agents with full Tor network access, integrating 18 dark web search engines, the Robin OSINT pipeline, and multiple LLM analysis modes for threat intelligence and forensics. 
    
    https://mcpmarket.com/server/onionclaw

*   Robin

    An open-source AI automation tool that refines dark web search queries, scrapes and filters .onion sites, and summarizes research findings. 
    
    https://www.youtube.com/watch?v=_KzObeom88Y&vl=en&t=286)


*   CrewAI Local Deep Researcher

    A multi-agent framework utilizing local models (like DeepSeek-R1 via Ollama) combined with deep search APIs like Linkup to orchestrate research, deduplication, and citation-backed writing.
    
    https://www.linkedin.com/posts/crewai-inc_crewai-multi-agent-deep-researcher-activity-7322633893172400129-gHzk)

*   Jar3d

    An open-source LangGraph agent powered by reasoning models (such as OpenAI's o1-preview) built for long-running research tasks, requirement gathering, and knowledge graph synthesis. 
    
    https://www.youtube.com/watch?v=UlKxDHqON5s)

*   Yutori Research API

    A multi-agent harness using 100+ Model Context Protocol (MCP) tools and live cloud browser agents to investigate interactive and login-gated deep web pages. 
    
    https://yutori.com/research
