*   agent harness AKA AI harness

    *   runtime scaffolding that turns a language model into an agent that can perform work
    
    *   drives model and tool calls
    
    *   manages conversation state and context
    
    *   applies approval policies
    
    *   can keep the agent progressing through a multistep task.

*   Agent Framework

    *   provides an opinionated, batteries-included Harness for 
    
        *   research
        
        *   coding
        
        *   data analysis
        
        *   long-running work
        
    *   user 
    
        *   provides a chat client and customize only the capabilities your application needs.
