# CmdStarter

cmdstarter.md

*   A REPL with history and completion, served locally or over a named pipe.

*   Command sequences and text pipes: a; b, a && b, a || b and a | b.

*   A daemon mode, which forwards the arguments of a process to a running copy of the application and runs them locally
    when none answers.

*   Trimming and Native AOT, for an application that has the command catalog that the package generates, measured on win-x64.

*   Microsoft dependency injection with one scope per execution, command filters and command states.
